1 Claude Code をインストール 必須 5分

デスクトップ版とVS Code版、両方インストールしてください。
普段はVS Code版をメインで使いますが、デスクトップ版も入れておくと便利です。

⚠ 最初にこれをやってください

Claude Code は Git Bash が必須です。

  1. git-scm.com/downloads/win から Git for Windows をダウンロード
  2. インストール時に「Add to PATH」にチェックを入れる
  3. インストール完了後、VS Code を再起動

インストール済みなのにエラーが出る場合：

PATHに通ってない可能性あり。Windowsの「システム環境変数の編集」→「環境変数」→「新規」で以下を追加：

CLAUDE_CODE_GIT_BASH_PATH = C:\Program Files\Git\bin\bash.exe

設定後、VS Code を再起動。

④ VS Code の基本操作（初めての人向け）

VS Codeを使ったことがある人はスキップOK。

やりたいこと操作
フォルダを開く「ファイル」→「フォルダーを開く」
ターミナルを開くCtrl + ` または「ターミナル」→「新しいターミナル」
ファイルを保存Ctrl + S（Macは Cmd + S）
コマンドパレットCtrl + Shift + P（Macは Cmd + Shift + P）
左サイドバーの切替Ctrl + B（Macは Cmd + B）

基本的にClaude Codeが全部やってくれるので、VS Codeの操作を覚える必要はほとんどありません。 困ったらClaude Codeに聞けばOK。

  1. claude.ai/download にアクセス
  2. お使いのOS用のインストーラーをダウンロード
  3. ダウンロードされたファイルを実行
  4. インストーラーの指示に従ってインストール
  5. インストール完了後、アプリを起動
  6. ログイン画面が表示される → 次のステップ2へ

「WindowsによってPCが保護されました」と出た場合：
「詳細情報」→「実行」をクリックすれば進めます。

3 Chrome拡張「Claude in Chrome」を入れる おすすめ 2分

Claude CodeがChromeブラウザを操作できるようになる拡張機能です。

  1. Chromeで Claude in Chrome を開く
  2. 「Chromeに追加」をクリック
  3. 追加後、拡張機能アイコンをクリックして接続を確認

なぜ入れるの？

これがあると、Claude CodeがWebページを直接見に行ける。

  • 「このURLの記事チェックして」→ 実際にページを開いて読む
  • 「競合サイトの構成を調べて」→ ブラウザで開いて抽出

ないとURLの中身が読めない。あると世界が変わります。

5 Git の初期設定 必須 2分

ターミナルの開き方：
VS Codeのメニュー「ターミナル」→「新しいターミナル」、または Ctrl + `
ターミナルの種類が「Git Bash」になっていることを確認してください。

ターミナルの開き方：
VS Codeのメニュー「ターミナル」→「新しいターミナル」、または Cmd + `
または Spotlight検索（Cmd + Space）で「ターミナル」と入力

① Gitが入っているか確認

git --version

バージョン番号が表示されればOK。

エラーが出る場合： ステップ1の Git for Windows がインストールされていない可能性あり。先にインストールしてください。

エラーが出る場合： 「Xcodeコマンドラインツールをインストールしますか？」と聞かれたら「インストール」を押してください。それでもダメならRenに連絡。

② 名前とメールアドレスを設定

git config --global user.name "自分の名前"
git config --global user.email "GitHubに登録したメールアドレス"

この設定は初回だけ。一度やれば次からは不要です。

6 作業リポジトリをダウンロード 必須 2分

Renから招待メールが届いたら、メール内の「View invitation」→「Accept invitation」で承認してください。

メールが届かない場合： Renに連絡してください。直接リンクで招待します。

承認後、ターミナルで以下を実行：

# デスクトップに移動
cd ~/Desktop

# リポジトリをダウンロード
git clone https://github.com/Ren-japan/star-team.git

# フォルダに入る
cd star-team
# デスクトップに移動
cd ~/Desktop

# リポジトリをダウンロード
git clone https://github.com/Ren-japan/star-team.git

# フォルダに入る
cd star-team

デスクトップに star-team フォルダができます。

自分の名前を登録する

以下のコマンドの Noah を自分の名前に書き換えて実行：

# Git Bash の場合
echo 'export STAR_TEAM_USER="Noah"' >> ~/.bashrc
source ~/.bashrc
echo 'export STAR_TEAM_USER="Noah"' >> ~/.zshrc
source ~/.zshrc

Noah の部分を自分の名前に変えてください（Kate / Rinon）

7 動作確認 必須 1分

全部うまくいったか確認します。ターミナルで以下を実行：

cd ~/Desktop/star-team
python3 manage.py list

python3 が使えない場合： python manage.py list で試してください。
それでもダメな場合は python.org からPythonをインストールしてください。インストール時に「Add to PATH」にチェックを忘れずに。

タスク一覧が表示されたらセットアップ完了です！

おつかれさまでした。 これで業務を始める準備が整いました。
具体的な業務の進め方は、初日にRenから説明します。

エラーが出た場合：

  • python3: command not found → python で試す。それでもダメならRenに連絡
  • No such file or directory → cd ~/Desktop/star-team を先に実行してから再度試す
  • その他のエラー → スクリーンショットを撮ってRenに送ってください

今までの会話から、私の以下の傾向をまとめてください。

1. 仕事の内容と目的（何をしている人か）
2. AIへの修正依頼・不満で多かったこと（「長い」「違う」「それじゃない」等）

4. 「これやるな」「こうしろ」と言ったルール・制約
5. よく頼む作業トップ3
6. 私が大事にしていそうな仕事の価値観・哲学（推測でOK）

箇条書きで簡潔にお願いします。

9 業務フォルダをセットアップ 必須 5分

Renから共有される ZIPファイル をダウンロードして、あなた専用のAI作業環境を作ります。

① ZIPをダウンロード・解凍

Renから共有されるリンクからZIPをダウンロードして解凍してください。
line-starter-kit というフォルダができます。

② フォルダ名を変更

line-starter-kit を 自分の名前に変更 してデスクトップに置いてください。

例:

  • Noah → project-noah
  • Kate → project-kate
  • Rinon → project-rinon

③ フォルダの中身

このフォルダが、あなたとAIの作業場所になります。

project-noah/
├── CLAUDE.md              ← AIへの業務マニュアル
├── roles/
│   ├── assistant/        ← あなた専用のAI人格（使うほど育つ）
│   │   ├── mind.md       ← 行動原則・好み
│   │   └── memory.md     ← 学び・進捗・申し送り
│   ├── cio/              ← データ分析の専門知識
│   └── cmo/              ← マーケ設計の専門知識
├── knowledge/            ← チーム共通のノウハウ集
│   ├── playbooks.md     ← 効いた施策パターン
│   ├── anti-patterns.md ← やっちゃダメ集
│   └── ...                ← その他の知識ファイル
└── files/                ← 参考資料・画像の置き場

④ Claude Codeで初回セットアップ

VS Codeでフォルダを開いて、Claude Codeを起動します。

  1. VS Codeで「ファイル」→「フォルダーを開く」→ デスクトップの project-〇〇 を選択
  2. Claude Codeを起動（右上の ✱ アイコン、または Ctrl + Shift + P → Claude Code）
  3. 自動でセットアップが始まります — 4つの質問に答えるだけ:
    • 名前
    • 担当業務
    • AIの話し方の好み
    • AI傾向分析の結果（ステップ8でやった人だけ）

「セットアップ完了！」と表示されたら準備完了。
あとは普通に話しかけるだけで業務を始められます。

自動セットアップが始まらない場合:
チャット欄に /setup と入力してEnterを押してください。

セットアップチェックリスト

  • VS Code をインストールした
  • VS Code を日本語化した
  • Claude Code 拡張をインストールした
  • デスクトップ版もインストールした
  • Claude Code にログインできた
  • （おすすめ）Chrome拡張を入れた
  • GitHubアカウントを作成した
  • ユーザー名をRenに伝えた
  • 招待メールを承認した
  • Git の初期設定をした（名前 + メール）
  • リポジトリを clone した
  • 自分の名前を登録した（STAR_TEAM_USER）
  • python3 manage.py list でタスクが表示された
  • （やっておくとスムーズ）AIの使用傾向を抽出した
  • 業務フォルダをセットアップした（ZIP解凍 → リネーム → /setup完了）

ステップ1〜2、4〜7が終わっていればOKです。
ステップ3・8は余裕があればやっておくとスムーズです。
業務の進め方は初日にRenから説明します。
