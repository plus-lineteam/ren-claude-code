# Session Wrap — セッション終了時の学習記録

タスクが一区切りついた時に、今セッションの学びをmemory.mdとknowledge/に確実に記録する。

## Step 1: セッション振り返り
1. 判断・発見: 新しく分かったこと、判断したことをリストアップ
2. 差し戻し・修正: renからのFBで直したことがあれば記録
3. データの発見: 予想と違ったデータ、新しいパターン
4. renの反応: 「いいね」「それ」と刺さったポイント

## Step 2: memory.md への追記
該当ロールのmemory.mdに1-3行で追記する:
- roles/ceo/memory.md → 判断の学び、差し戻しパターン、renの好み
- roles/cio/memory.md → データの発見、数値の落とし穴
- roles/cmo/memory.md → ジャンル知識、レビュー基準、施策の学び

追記フォーマット: - {何が起きたか} → {教訓/学び}（{日付}）

## Step 3: knowledge/ 昇格判定
差し戻し・教訓・学びが出たら、デフォルトでknowledge/に追記する。memory.mdに溜め込まない。
- 差し戻し・やらかし → knowledge/anti-patterns.md
- 施策で効果確認 → knowledge/playbooks.md
- ジャンル固有の新事実 → knowledge/genre-insights.md
- ファネル指標の発見 → knowledge/funnel-model.md

mind.mdには触るな。renが明示的に指示した時だけ。

## Step 4: 次回への申し送り
次セッションの自分に伝えたいことがあれば、memory.md末尾に記録。
