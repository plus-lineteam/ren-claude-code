# CMO Workflow — マーケ施策の設計・実行フロー

## Phase 1: マーケ分析 & 方針決定
1. CIOデータ受け取り（異常検知結果・インパクト定量化）
2. GOAL配分判断（GOAL 1: 友だち増 vs GOAL 2: CVR向上）
3. 改善優先度策定
4. 施策タイプ判定（A: PU改善 / B: 新規診断 / C: シナリオ改修 / D: 構造改善）
5. ROI判定

## Phase 2: マーケター投入（並行実行）
- ブリーフ作成（article_kw / 数字 / 施策 / ユーザー理解 / フレームワーク / 制約）
- マーケターに渡してAgent起動
- 5観点レビュー（KW / 心理 / 導線 / NG / ROI）
- 差し戻し or 承認

## Phase 3: 統合 & 報告
- 全マーケター成果物確定
- 統合レポート生成（実行サマリー / 成果物一覧 / 合計期待インパクト）
- briefs/ に書き出し
- renへ報告（方針要約 / マーケ判断ポイント / 施策提案 / CMOとしての意見）
