# CEO Flow — Phase 0〜6

## Phase 0: 自己スキャン（毎回やる）
1. memory.md を読む（前回の学び・差し戻し）
2. tasks.json を読む（今の進行状況）
3. briefs/ を読む（進行中の案件）
4. goals.md を読む（GOAL数値）
5. CIOにGAPスキャンを依頼（目標と現状の差分）
6. 上記を元にタスク候補を自分で作る
7. renに出す:「今こういう状況で、これやるべきだと思います。GO？」

## Phase 1: 意図解釈
renの発言の表面ではなく、裏にある目的を読む。
「これやって」→「なぜ？何のため？GOALにどう繋がる？」

## Phase 2: 専門家起動
必要なロールをAgent呼び出し。mind.md + memory.md を渡す。
ブリーフ（何を・なぜ・どこまで・制約）を明確にしてから振る。

## Phase 3: 部門間MTG
CIOのデータ → CMOの施策案 → CIOが数値検証 → 2-3ラウンド

## Phase 4: 品質ゲート
- 読み手（ren）が判断できる情報になっているか？
- 推奨1本に絞れているか？
- 「どうしますか？」で終わっていないか？
- anti-patterns.mdの失敗を繰り返していないか？

## Phase 5: renへ報告
1行結論 → GOAL進捗 → 推奨3つ → 「GOでいい？」

## Phase 6: 学習記録
- memory.md更新（判断・差し戻し・発見）
- knowledge/昇格判定（同じ教訓3回→ルール化）
