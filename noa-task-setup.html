🟢 タスクボード連携セットアップ

Noa用 — Claude Codeのチャットにこのページの指示を貼るだけ

GOAL: Noaが以下の3つを使える状態にする

  1. タスクボード（line-team リポ）→ タスクの追加・更新・完了をgit経由で管理
  2. renのスキル・knowledge（claude-projects リポ）→ 読み取り専用で参照
  3. クラウドボード → ブラウザでタスク確認

⚠️ 重要ルール

  • line-team リポ → Write権限あり。タスク管理で使う。pushしていい
  • claude-projects リポ → Read-only。絶対にpushしない。 参考・スキル取得用。git pull だけ

セットアップ手順

以下を Claude Codeのチャットに貼って「全部実行して」 と言うだけ。

1 line-teamをクローン（タスク管理用） 
cd "$HOME\OneDrive\デスクトップ\project-noa"
git clone https://plussaitounoa-lgtm@github.com/Ren-japan/line-team.git

GitHubの認証を求められたらログイン。

2 claude-projectsをクローン（参考用・Read-only） 
cd "$HOME\OneDrive\デスクトップ\project-noa"
git clone https://plussaitounoa-lgtm@github.com/Ren-japan/claude-projects.git

※既にある場合は cd claude-projects && git pull でOK

3 タスク管理の動作確認 
cd "$HOME\OneDrive\デスクトップ\project-noa\line-team"
python3 manage.py list

タスク一覧が表示されればOK。

4 テストタスクを追加してpush 
python3 manage.py add --title "セットアップ完了確認" --purpose "タスク操作〜pushが通ることを確認" --assignee Noa --created-by Noa
git add data/tasks.json
git commit -m "test: セットアップ確認 (Noa)"
git push

push成功したら クラウドボード を開いてタスクが見えるか確認。

5 CLAUDE.mdにタスク管理設定を追記

以下をCLAUDE.mdの末尾に追記：

## タスク管理

チームのタスクボードは line-team リポで管理。

- タスク管理リポ: ~/OneDrive/デスクトップ/project-noa/line-team/
- 参考リポ（Read-only）: ~/OneDrive/デスクトップ/project-noa/claude-projects/
- クラウドボード: https://line-team-board.streamlit.app/noa

### 操作手順

cd ~/OneDrive/デスクトップ/project-noa/line-team
git pull
python3 manage.py <コマンド>
git add data/tasks.json
git commit -m "update: 内容 (Noa)"
git push

### コマンド

- 自分のタスク確認: python3 manage.py list --assignee Noa
- 全タスク確認: python3 manage.py list
- ステータス変更: python3 manage.py update t5 --column done
- メモ追加: python3 manage.py note t5 "作業メモ"
- タスク追加: python3 manage.py add --title "タイトル" --purpose "目的" --assignee Noa --created-by Noa

### ルール

- 操作前に必ず git pull
- 操作後は必ず git push（data/tasks.json だけaddする）
- claude-projects は絶対にpushしない（Read-only）
- 会話中にタスクが発生したら自動でtasks.jsonに追加する
